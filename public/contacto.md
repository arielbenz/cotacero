# Escribinos

Cada dato corregido, cada zona que falta y cada texto que no se entiende mejora la app para toda la ciudad.

_El formulario se completa en [la página](https://cotacerosf.com/contacto)._

Es lo único que manda texto tuyo a un servidor. **No se guarda tu IP**: se usa sólo para limitar envíos, transformada de modo irreversible. Si dejás un contacto, se usa únicamente para responderte. **No pongas tu dirección.** [Qué se guarda](https://cotacerosf.com/legal#privacidad).

## ¿Encontraste un dato mal?

Es lo más valioso que nos podés mandar. Decinos la dirección o el lugar exacto: con eso se comprueba contra la fuente.

## ¿Sos de un organismo o de prensa?

El modelo busca revisión técnica. Si podés ayudar a validarlo, escribinos. [La metodología](https://cotacerosf.com/datos).
